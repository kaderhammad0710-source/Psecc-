# PSEC — Protocole de Sécurité à Enveloppe Cyclique

Architecture de sécurité décentralisée combinant :
- Labyrinthe cyclique (honeypot dynamique indétectable)
- Détection comportementale de l'observateur
- Fragmentation des données en chaîne distribuée

Chaque utilisateur est un nœud. Les données fragmentées
sont du bruit sans la clé comportementale légitime.

Projet open source. Contributions bienvenues.
